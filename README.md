# CodeAlpha Stock Portfolio Tracker
## Project Description
This project is a simple Stock Portfolio Tracker developed using Python as part of the CodeAlpha Python Programming Internship.
The program allows the user to enter stock names and quantities and calculates the total investment value based on predefined stock prices.
## Features
- Displays available stocks and their prices
- Allows users to enter stock names
- Allows users to enter quantities
- Calculates investment value for each stock
- Calculates total investment value
- Handles invalid stock names
- Handles invalid quantity input
## Technologies Used
- Python
- Dictionary
- User Input
- Conditional Statements
- Loops
- Basic Arithmetic
- Exception Handling
## Available Stocks
- AAPL
- TSLA
- GOOGL
- MSFT
- AMZN
## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run: python stock_portfolio.py
6. Enter the stock name and quantity when prompted.
